**中轴价格策略规则（确认版）**
```
初始中轴 = 前90日均价
底仓 = 投资上限 × 50%（固定不动）
浮动仓 = 动态调整，上限 = 投资上限 × 100%（总仓位可达150%）
触发阈值 = 股价较中轴 ±8%
调整幅度 = 投资上限 × 20%（每次买卖20万）
中轴更新 = 每次交易后更新为成交价
止损 = 无
```
