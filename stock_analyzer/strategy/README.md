# 中轴价格仓位控制策略 - 最终版

## 策略概述

基于持仓股的中轴价格（前90日均价）进行动态仓位管理的量化策略。根据股票波动特征自动匹配最适合的交易节奏。

---

## 核心规则

### 基础参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 初始中轴 | 前90日均价 | 建仓日的90天平均收盘价 |
| 底仓比例 | 50% | 投资上限的50%，固定不动 |
| 浮动仓上限 | 100% | 投资上限的100%，动态调整 |
| 触发阈值 | ±8% | 股价较中轴偏离8%触发交易 |
| 调整幅度 | 20% | 每次买卖投资上限的20% |
| 中轴更新 | 成交价 | 每次交易后更新中轴为成交价 |

### 建仓规则
- **建仓日**：第90个交易日
- **建仓价格**：第90日开盘价
- **底仓数量**：投资上限 × 50% ÷ 建仓价

---

## 智能自适应冷却机制（方案3c）

### 股票类型判定
在建仓日（第90天）自动计算股票波动特征：

```
波动率评分 = min(100, 年化波动率 × 50 + ATR% × 10)

其中：
- 年化波动率 = 前60-89天收盘价涨跌幅标准差 × √252
- ATR% = (第89日ATR / 第89日收盘价) × 100
```

**判定标准：**
- 评分 > 60 → **高波动股 (high_vol)**
- 评分 ≤ 60 → **普通股 (normal)**

### 高波动股策略（分级冷却）

| 触发条件 | 冷却期 | 说明 |
|----------|--------|------|
| 卖出后 | 15天 | 短冷却，更快接回 |
| 买入后偏离 ≤ -12% | 10天 | 深度下跌，加速抄底 |
| 买入后偏离 ≤ -10% | 15天 | 中度下跌 |
| 买入后偏离 > -10% | 20天 | 轻度下跌 |

### 普通股策略（自适应冷却）

根据实时波动率动态调整冷却期：

| 波动率评分 | 冷却期 | 市场状态 |
|-----------|--------|----------|
| < 20 | 10天 | 低波动，多交易 |
| 20-40 | 15天 | 中低波动 |
| 40-60 | 20天 | 中等波动（默认） |
| 60-80 | 25天 | 中高波动 |
| ≥ 80 | 30天 | 高波动，少交易 |

---

## 交易逻辑

### 买入条件
1. 股价较中轴下跌 **≥ 8%**
2. 满足冷却期要求
3. 浮动仓未达上限（投资上限的100%）
4. 现金充足

### 卖出条件
1. 股价较中轴上涨 **≥ 8%**
2. 浮动仓 > 0
3. 满足冷却期要求

### 交易执行
- 买卖数量 = 投资上限 × 20% ÷ 当前价格（取整）
- 成交后更新中轴价格为成交价
- 记录交易时间用于冷却期计算

## 新增持仓处理流程

```
1. 获取新持仓股票历史数据
2. 计算建仓日（第90天）波动特征
3. 判定股票类型（normal/high_vol）
4. 为该股票绑定对应策略
5. 后续交易自动使用该策略参数
```

---

## 风险控制

1. **无止损**：策略依赖中轴回归，不设止损
2. **仓位上限**：总仓位不超过投资上限的150%（底仓50%+浮动仓100%）
3. **冷却机制**：避免过度交易，减少摩擦成本
4. **动态调整**：根据市场波动自动调整交易频率

---

## 适用场景

- **震荡市**：高波动股反复做T，收益最佳
- **趋势市**：普通股减少交易，避免追高杀跌
- **混合持仓**：不同类型股票自动匹配最优策略

---

## 注意事项

1. 策略回测基于历史数据，未来表现可能不同
2. 高波动策略交易频繁，需考虑交易成本
3. 建议定期（每季度） review 策略有效性
4. 极端行情（如连续涨停/跌停）可能导致策略失效
