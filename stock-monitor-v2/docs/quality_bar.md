# 深度报告质量基准（Quality Bar）

> 来源：2026-09-22 用户以豆包盘中分析为对标逐轮调教后固化。
> 用途：每次报告生成/每次功能迭代后对照本清单自检；质检不过不许交付。
> 维护：发现新差距先补这份清单，再补代码。

## A. 时效与联动
- [ ] A1 所有行情/事件数据标注"截至 HH:MM"时点；盘中请求必须实时出，不等定时任务
- [ ] A2 持仓联动：成本/股数/浮亏精确计算，与最新价联动刷新
- [ ] A3 报告生成后发生的新事件，报告不得装作知道（快照属性明示或前端动态加载）

## B. 盘面结构（第五波已装）
- [ ] B1 盘中节奏：分时时间轴叙事（开→高→低→现价+时间戳），分钟数据缺失时降级快照点位，禁写"无数据"
- [ ] B2 三日形态：规则引擎定性（动能三连衰减/三连阳阴/缩量回踩/放量突破/横盘蓄势），附判定依据
- [ ] B3 板块背离：个股 vs 板块指数/基准，精确到0.01pct，写清参照系+强弱判定句
- [ ] B4 投行一致预期表：含PE列（现价÷EPS），注明价格口径

## C. 消息面深度（第六波已装）
- [ ] C1 券商观点雷达：机构名+动作（上调/维持/重申/目标价）+对象+日期，逐条可溯
- [ ] C2 产业价格锚：具体价格数据（美元/Gb、元/吨、环比%）+来源（TrendForce/瑞银/Counterpoint等）
- [ ] C3 压制项清单：担保余额/质押/解禁/折价/定增浮亏结构化列出，与利好段并列——只讲利好=不及格
- [ ] C4 事件进展链：同一事件首曝→跟进时间线（9/15首曝→9/22券商点评），标事件条数

## D. 研判与验证
- [ ] D1 综合研判：多空平衡，给明确立场（偏空/中性/偏多），附编号论证
- [ ] D2 验证点：给出可回验的具体价位/条件，接入验证引擎 d1/d3/d5 回访
- [ ] D3 风险提示：每条带传导机制，不堆名词
- [ ] D4 信息来源清单：逐条列出，全部真实可溯，禁止编造数字

## E. 自律条款
- [ ] E1 数据旧于对手即失败（对手把"回购完毕"写成"进行中"=我们赢的点，保持数据新鲜度优势）
- [ ] E2 对手没有的我们要有：中轴价/触发买卖点/验证引擎回访结论
- [ ] E3 免责声明保留："以上内容由AI辅助生成，仅用于信息整理和投研辅助，不构成投资建议"
